# H-C/P-D 侧关系重构候选审计

## 1. 审计问题

HPLGA 在四库冻结 Gate 1 判定 No-Go 后，曾考虑增加 H-C/P-D 侧关系辅助重构：

```text
主任务：预测 Compound-Protein
辅助任务：重构 Herb-Compound 与 Protein-Disease
```

候选目标是约束 compound、protein 与对应超边表示保留侧关系拓扑，并尝试作为
第三项模型机制。该方向必须同时通过两个串联门槛：

1. **创新性门槛**：不能与已有 DTI 异构网络拓扑保持或多关系重构目标高度同构；
2. **表示空间门槛**：冻结 Hctx-P 表示仍需在真实侧边和度数匹配非边之间保留
   可学习但尚未充分编码的空间。

任一门槛失败即停止，不进入训练实现或参数搜索。

## 2. 近邻工作核验

### 2.1 NeoDTI 已直接重构全部异构关系

[NeoDTI](https://academic.oup.com/bioinformatics/article/35/1/104/5047760)
在异构药物网络中对每种关系使用关系特定投影，并联合最小化各类边权的重构误差。
其目标函数对所有关系类型求和，药物—疾病、蛋白—疾病、药物—蛋白及相似性网络
均属于被重构对象。

该论文还进行了直接消融：只重构 DTI 边而不重构其他关系时，AUPR 下降
`5.5%`、AUROC 下降 `2.7%`。因此，“利用辅助关系重构正则化 DTI 表示”并非
尚未出现的机制，而是已有 DTI 拓扑保持学习的核心组成。

### 2.2 后续工作已把该机制视为已有范式

[HampDTI](https://academic.oup.com/bib/article/23/4/bbac184/6596318)
将 NeoDTI 概括为通过重构异构网络边权学习拓扑保持节点表示，并将其作为直接
基线。这说明多关系拓扑重构已进入 DTI 方法谱系，而不是仅存在于通用图自编码器。

[GAEMSDNN](https://pubmed.ncbi.nlm.nih.gov/36107905/) 等后续 DTI 方法也继续使用
图自编码器和重构信息增强表示。即便将关系名称替换为 H-C/P-D，核心训练动作仍然
是已有的侧网络重构正则。

## 3. 与当前候选的同构关系

| 候选设计 | 已有近邻工作 |
|---|---|
| H-C 与 P-D 分别作为辅助关系 | NeoDTI 对药物、蛋白、疾病等多关系网络联合建模 |
| 关系特定投影后重构边 | NeoDTI 使用关系特定的左右投影矩阵重构边权 |
| 与 C-P 主损失联合优化 | NeoDTI 联合优化 DTI 与其他网络重构误差 |
| 用侧关系改善冷启动表示 | 异构 DTI/图自编码器方法已将侧信息用于未见实体表示 |

当前项目可以把 H-C/P-D 重构作为一个有出处的训练正则或基线，但不能仅凭
“应用到中草药超图”将其表述为独立第三创新点。

## 4. 冻结判定

**结论：No-Go（创新性门槛）。**

由于两个门槛是串联关系，创新性门槛已经失败，因此：

1. 不编写冻结表示重构 probe；
2. 不实现 H-C/P-D 辅助重构损失；
3. 不搜索重构权重、负采样比例或关系解码器；
4. 不将该方向改名为 topology consistency、side reconstruction 或
   multi-task preservation 后重新开放；
5. 若将来只把它作为训练正则使用，必须引用 NeoDTI 等直接先例，并降级为工程
   组件，不能列入核心贡献。

未执行表示空间门槛不代表 frozen representation 已经充分重构 H-C/P-D，而是
表示：即使 headroom 存在，也不能解决该候选缺乏方法新颖性的问题。

## 5. 对下一步的约束

当前不再通过连续增加匿名拓扑模块来凑足“三个模型创新”。更可信的投稿结构是：

1. **Hctx-P**：候选级药材上下文—靶点交互；
2. **SDIS**：compound cold-start 下的训练支持度解耦评分；
3. **Strict benchmark 与 ETCM2.0 数据/证据闭环**：逐折无泄漏、多数据库
   cold-start 评估、实体映射和冻结 Top-K 外部核验。

下一项高价值实验不是新重构损失，而是补齐四库 compound cold-start 的
`NoContext -> Hctx-P -> Hctx-P + SDIS` 完整链条，使两个模型机制在同一协议中
形成可解释的递进关系。该实验完成后应停止模型搜索，进入 Methods、Results 和
审稿风险检查。
